# Recursos visuales

Logo original del proyecto: plato y cubiertos en la paleta terracota y crema de Restaurante App. Se utiliza en el acceso, el menú y el icono de ventana.

Los diez íconos son dibujos vectoriales originales para navegación y acciones. Cada SVG editable tiene su PNG de uso; Tkinter carga los PNG con PhotoImage sin dependencias externas. Los SVG no se procesan durante la ejecución.

No se copiaron imágenes del ejemplo docente ni se requieren descargas al abrir la aplicación. Se consultó https://fonts.google.com/icons como referencia de iconografía funcional.
