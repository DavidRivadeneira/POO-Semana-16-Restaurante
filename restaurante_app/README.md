# Restaurante App · Semana 16

Juan David Rivadeneira Cuascota · Universidad Estatal Amazónica

Programación Orientada a Objetos · Segundo semestre · Paralelo F

Evolución de Semana 15: conserva login, productos, ventas, JSON y recursos visuales.
Incorpora CRUD de empleados/clientes para el Administrador y los eventos
`<<TreeviewSelect>>`, `<Return>`, `<Escape>` y `<<ComboboxSelected>>` con `bind()`.
Los botones conservan `command=` y reutilizan los mismos métodos.

Desde esta carpeta:

```bash
python main.py
```

En Windows también puede usarse `py main.py`.
Acceso de demostración: **ana / 1234 · Administrador**.

Abrir Usuarios, completar el formulario y pulsar Registrar o Enter. Seleccionar
una fila para cargarla y actualizar o eliminar con confirmación. Escape limpia
el formulario y cancela la selección. Cerrar y volver a abrir permite comprobar
la recuperación desde usuarios.json.

Consultar el [README principal](../README.md) para estructura, continuidad,
roles, eventos, persistencia, pruebas, rúbrica y enlace de entrega.
