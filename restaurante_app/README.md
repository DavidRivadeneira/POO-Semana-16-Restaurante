# Restaurante App · Semana 15

Juan David Rivadeneira Cuascota · Universidad Estatal Amazónica
Programación Orientada a Objetos · Segundo semestre · Paralelo F

Evolución de Semana 14: conserva acceso, usuarios y gestión de productos;
incorpora ventas con command, callbacks, validaciones en el servicio y JSON.
La interfaz integra logo e íconos desde assets.

Desde esta carpeta:

    python main.py

En Windows también puede usarse **py main.py**.
Acceso de demostración: **ana / 1234**.

Abrir **Ventas**, seleccionar un usuario y un producto y pulsar **Registrar venta**.
La tabla y el contador se actualizan. Cerrar y volver a abrir permite comprobar
la recuperación de las ventas guardadas.

Consultar el [README principal](../README.md) para la estructura, continuidad,
explicación de eventos, persistencia, pruebas, rúbrica y enlace de entrega.
