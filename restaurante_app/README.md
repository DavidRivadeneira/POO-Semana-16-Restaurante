# Restaurante App · Semana 14

**Juan David Rivadeneira Cuascota · Universidad Estatal Amazónica**

**Programación Orientada a Objetos · Segundo semestre · Paralelo F**

Evolución de la Semana 13 con componentes y contenedores de Tkinter. Conserva
el acceso y la consulta de usuarios; añade registro, carga por código,
actualización y eliminación de productos mediante servicios y archivos JSON.

Desde esta carpeta:

```powershell
python main.py
```

En Windows también puede utilizarse `py main.py`.

Acceso de demostración: usuario **ana**, contraseña **1234**.

Flujo: **Login → Panel principal → Productos / Usuarios → Cerrar sesión → Login**.
En Productos, escribir un código y pulsar **Cargar por código** para consultar.
Los botones **Registrar**, **Actualizar** y **Eliminar** guardan los cambios;
**Limpiar** solo reinicia el formulario. La tabla se actualiza después de operar.
La opción **Ventas (pendiente)** presenta un aviso de desarrollo futuro.

Consultar el [README principal](../README.md) para los datos académicos, la
estructura, componentes, responsabilidades, continuidad con Semana 13,
persistencia y secuencia de comprobación de las operaciones.
